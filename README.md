# Paul George

**Technical discovery, integrations and web delivery in UK PropTech.**

I’m a Senior Front-End Developer based in Cornwall. I build and support estate agency websites, connect them to CRM systems and property feeds, and trace problems across the systems that handle listings and enquiries.

When I build an integration, I work out which system owns the data, what the website needs to validate, and where each enquiry should go. I agree how we’ll check it at launch and document what support needs to know when something changes.

## What I work on

- **Integrations** for CRM systems, property feeds and enquiries, with end-to-end testing.
- **Web platforms** with custom WordPress themes, plugins and reusable editing controls, with attention to performance and accessibility.
- **Technical delivery** from requirements analysis and migrations through release checks, handover and production troubleshooting.
- **Developer workflows** covering Git adoption and training, build automation and documentation. I use AI-assisted tools for prototyping and debugging.

I work with WordPress, PHP, JavaScript and TypeScript, CSS and SCSS, Astro, React, Next.js and Git.
